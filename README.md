# BoysFishing

## 게임 개요

낚시를 통해 여러 지역을 탐험하고 다양한 물고기를 모으는 데스크탑 컴패니언 장르의 방치형 게임입니다.

## 플레이 방법

### 낚시

붉은색 마름모 버튼을 누르면 낚시 시작/종료를 할 수 있습니다.

입질이 오면 버튼 위의 물고기 체력바가 갱신되고, 체력바의 초록 게이지가 다 줄어들기 전까지 물고기의 체력을 모두 소모시키면 물고기를 낚을 수 있습니다.

기본적으로 자동 공격을 합니다. 배 부근을 클릭하면 수동 공격을 하여 더 빨리 잡을 수 있습니다.

현재 드랍테이블 작업 도중이라 보스를 제외한 모든 물고기가 같은 확률로 나옵니다.

### 노트 UI

우측 하단의 책모양 버튼을 누르면 노트 UI를 켤 수 있습니다.

인벤토리, 장비창, 장비 강화, 제작, 상점, 지도, 도감, 설정을 볼 수 있습니다.

### 인벤토리

현재 소지중인 아이템의 목록과 그와 관련된 서브 탭을 열람 가능합니다.

**1. 플레이어 정보**

플레이어의 현재 장비, 스탯을 볼 수 있습니다.

인벤토리에서 장비를 클릭 후 장비 슬롯을 클릭하면 장착할 수 있습니다. 포커스가 없어서 일일히 눌러봐야합니다...

**2. 강화**

장비는 강화를 할 수 있습니다.

인벤토리에서 장비를 클릭 후 우측의 큰 슬롯을 클릭하면 강화 정보와 재료가 충분하다면 강화를 할 수 있습니다.

**3. 제작**

재료를 소모해 다양한 아이템을 제작할 수 있습니다.

상단의 목록에서 원하는 아이템을 선택하면 제작 정보와 재료가 충분하다면 제작을 할 수 있습니다.

**4. 상점**

골드를 소모해 상점에서 아이템을 구매할 수 있습니다.

### 지도

푸른색 GPS 버튼을 누르면 지도를 열 수 있습니다.

지도에서 지역을 선택해 이동할 수 있습니다.

### 도감

지금까지 낚은 물고기의 정보를 열람할 수 있습니다.

필터 및 정렬 기능이 있습니다.

### 설정

톱니바퀴 모양 버튼을 누르면 해상도 설정창을 열 수 있습니다.

**게임종료**

1. 붉은색 게임종료 버튼을 누르면 게임이 종료됩니다. 세이브는 자동으로 됩니다.

**화면 설정**

1. 모니터를 변경할 수 있습니다.
2. 전체/창 화면을 선택할 수 있습니다.
3. 강제 포커스를 키면 다른 응용 프로그램 위에 오버랩 됩니다.
4. 창화면일 때 Scale을 조절해 게임의 크기를 조절할 수 있습니다.
5. 창화면일 때 이동모드를 토글하면 창을 이동시킬 수 있습니다.
6. 창화면일 때 크롭 슬라이더를 조절해 좌우의 보이는 영역을 조절 가능합니다.

## 발견된 버그

1. 설정의 강제 포커스 토글의 애니메이션이 작동 안합니다. 기능은 정상입니다. 다른 탭으로 넘어간 다음 다시 설정탭으로 돌아오면 현재 상태로 토글이 갱신됩니다.
2. 낚시 성공 시 팝업이 배경 뒤로갑니다.
